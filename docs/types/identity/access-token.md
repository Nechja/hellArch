OAuth 2.0 access token (short-lived, 1 hour). Used as Bearer token for API authentication.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `token_hash` | string | SHA-256 hash of the token |
| `user_id` | uuid | Owner user ID |
| `client_id` | string | OAuth client that issued the token |
| `scope` | string | Granted scopes |
| `expires_at` | datetime | Token expiration |
| `created_at` | datetime | Token creation timestamp |
| `client_fingerprint` | string? | SHA-256 hash of client IP + User-Agent |

## Security

- **Stored as hash**: Raw token is never persisted, only SHA-256 hash
- **Client binding**: Token is rejected if fingerprint doesn't match
- **Short-lived**: 1 hour expiration limits exposure window
